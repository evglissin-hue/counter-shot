# Keepfall (working title)

A physics-heavy 3D castle duel for the browser: first-person siege weapons, minions, and a castle to run. Keepfall is a working title; the repo keeps the name counter-shot until the final name is chosen.

The spec draft is `SPEC.md`; decisions and findings so far are in `docs/plan.md`. The `lab/` folder holds the test page that measures each device (physics, graphics, determinism) and previews art styles.

## Lab

```bash
npm install
npm run lab:dev
```
